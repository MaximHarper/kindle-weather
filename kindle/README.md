# Kindle-side files

Copied onto the Kindle 4's USB drive on top of [kindle-dash v1.0.0-beta.4](https://github.com/pascalw/kindle-dash/releases/tag/v1.0.0-beta.4):

- `dashboard/local/env.sh` – refresh schedule (:20 and :50, 06:20–23:50 London), no sleep screen
- `dashboard/local/fetch-dashboard.sh` – downloads `dashboard.png` from this repo's `dashboard` branch
- `extensions/kindle-dash/` – KUAL menu entry "Start weather dashboard"

Prerequisites on the Kindle: K4 jailbreak, MKK (`Update_mkk-…-k4-ALL_install.bin`) and KUAL (`KUAL-KDK-1.0.azw2` in `documents/`).

Start: KUAL → Weather dashboard → Start weather dashboard.
Stop: hold the power button ~20 s to restart the Kindle into normal reading mode.
